# Execution plans

Use a checked-in plan for work that crosses packages, changes a contract or migration, has material
financial/security risk, or is unlikely to finish in one short session. Copy `TEMPLATE.md` into
`active/<yyyy-mm-dd>-<slug>.md`; move it to `completed/` after recording the outcome.

Plans are resumable state, not status theatre. Keep acceptance checks, progress, decisions,
observations, and remaining risks current. Small local changes can use an ephemeral plan.
